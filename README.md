# Parking Management System

A system that handle a parking lot

## What I used
- Java
- SQLite database
- JDBC for connection

## What it does
- Tracks which parking spots are available/occupied
- Assigns a spot when a vehicle enters
- Frees the spot when vehicle exits
- Stores vehicle records (plate number, type of vehicle, entry time, spot number)
- Issues a fine if vehicle exceeds the time limit

## What I learned
- How to connect Java to SQLite using JDBC
- How to calculate time differences in Java
- How to write SQL INSERT, UPDATE, and SELECT queries
